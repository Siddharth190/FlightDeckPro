# ✈️ FlightDeckPro

A modern aviation companion mobile app built with React Native and Expo that provides pilots and aviation enthusiasts with aircraft data, airport information, emergency checklists, weather utilities, navigation tools, and flight-related calculations — all in one sleek interface.

---

## 🚀 Features

- 🛩️ Massive Aircraft Database
- 🛫 Airport Information System
- 📋 Emergency Checklists
- 🌦️ Weather & Flight Utilities
- 🧭 Navigation Tools
- 📡 Live Location Support
- 📊 Aviation Calculators
- 📱 Cross Platform Support (Android, iOS, Web)
- 🎨 Modern Aviation-Themed UI
- ⚡ Built with Expo + React Native

---

## 🛠️ Tech Stack

- React Native
- Expo
- TypeScript
- React Navigation
- Expo Location API
- Lucide React Native Icons

## 📦 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/FlightDeckPro.git
cd FlightDeckPro
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start the Development Server

```bash
npx expo start
```

---

## ▶️ Running the App

### Android

```bash
npm run android
```

### iOS

```bash
npm run ios
```

### Web

```bash
npm run web
```
